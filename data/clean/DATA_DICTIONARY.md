# Словарь данных: `data/clean/`

Чистый слой данных проекта «Калькулятор прогноза урожайности». Таблицы собираются из `data/raw/` одной командой:

```bash
uv run python -I -X utf8 src/preprocess/build_all.py
```

Отдельные шаги: `build_all.py regions crops yield weather soil ndvi modis calendar prices economics model_table`.

Параметры сборки:

| параметр | по умолчанию | на что влияет |
|---|---|---|
| `--train-end-year` | 2021 | Нормы климата (`a_*`, `clim_*`, `a_win_*`) считаются только по сезонам 2001…этот год |
| `--category` | 1 | Категория хозяйств в `model_table`: 1 — все категории, 2 — СХО, 8 — КФХ и ИП, 17 — хозяйства населения |
| `--price-base-year` | 2021 | Базовый год реальных цен (`price_real`) |
| `--crops` | все | Фильтр культур для `model_table`, через запятую, например `1010400,3080000` |
| `--force` | — | Пересобрать кэш: разбор ЕМИСС, суточную погоду и точки NDVI и MODIS |

Кэш промежуточных файлов лежит в `data/clean/_cache/`, сводки шагов — в `data/clean/_stats/*.json`. Проверки: `uv run pytest -q tests/test_clean_data.py`. Отчёт о сборке — [reports/preprocess.md](../../reports/preprocess.md).

## Общие соглашения

- **`okato`** — каноничный код территории, 11 цифр, как в `data/raw/geo/regions.csv` (89 субъектов). Так же устроены точки пашни, погода и почвы. ФО — коды ЕМИСС (`region_level = fo`). Россия — `643`: до 2022 года это код 643 ЕМИСС, с 2023 года — `643004.АГ` («без новых субъектов»). Исходный код ЕМИСС сохраняется в `okato_src`.
  - **Тюменская обл.:** каноничный код `71001000000` («без ХМАО и ЯНАО»). Ряд ЕМИСС «без АО» идёт с 2007 года; более ранние годы и недостающие культуры берутся из ряда «с АО» (`71000000000`, видно по `okato_src`). В АО пашни почти нет.
  - **Архангельская обл.:** код `11000000000` («с НАО», как в ЕМИСС). Полигон и точки пашни — без НАО. НАО — отдельный субъект `11100000000`, поэтому при суммировании по субъектам НАО учтётся дважды (доли процента площади).
- **`crop_code`** — код культуры ЕМИСС (справочник `crops.parquet`).
- **`farm_category_code`**: 1 — хозяйства всех категорий, 2 — с/х организации (СХО), 8 — КФХ и ИП, 17 — хозяйства населения.
- **Сезон Y** для погоды — сентябрь Y−1 … октябрь Y. Месячные теги колонок: `p09…p12` — осень Y−1, `01…10` — месяцы года урожая.
- **Ничего не удаляется.** Исходное значение хранится рядом с очищенным, правила чистки записаны во флагах `flag_*`.
- `float32` — у погоды, NDVI, почв и `model_table`; остальное хранится в `float64`.

| `okato_with_ao`, `okato_without_ao`, `ao_split`, `geometry_excludes_ao` | Коды ЕМИСС «с АО» и «без АО» для Архангельской и Тюменской обл.; признак, что полигон не включает АО |

| `cropland_from_worldcover` | Есть хотя бы одна точка, отобранная по WorldCover |

## 2. `crops.parquet` — справочник культур

Ключ: `crop_code`. Объединяет коды урожайности (31533), площадей (31328) и сбора (30950).

| колонка | описание |
|---|---|
| `crop_name` | Название культуры в ЕМИСС |
| `y0_/y1_/n_reg_<id>` | Первый и последний год, число территорий с данными в показателе 31533, 31328 или 30950 |
| `has_yield/has_area/has_gross` | Есть ли культура в соответствующем показателе |
| `base_crop_code`, `after_processing` | Ряды «в весе после доработки» (3080102, 3100009, 3130201, …) ссылаются на основную культуру. Это отдельный показатель, а не дубль: ряды обрываются в 2022–2023 гг. |
| `area_alias_of` | Код площади 31328, который заменяет код культуры, если основного нет: 3080100 «Подсолнечник на зерно» (с 2022 г.) → 3080000; 3010101 «Лен-долгунец» (2022) → 3010300 |
| `area_code` | Код посевной площади для расчётной урожайности (у культур «после доработки» — площадь основной культуры) |
| `components` | Из чего складывается «всего»: 1010401 = 1010400 + 1010500 («пшеница всего» в 31533 есть только с 2007 г.), то же для ржи, ячменя и рапса |
| `is_aggregate` | Группа или итог (зерновые всего, масличные, вся посевная и т. п.) |
| `group` | Группа: зерновые, зернобобовые, масличные, технические, картофель, овощи и бахчевые, кормовые, плодово-ягодные, итого |
| `season_type` | Тип сезона: озимая, яровая, смешанная (озимые + яровые), многолетняя, н/д |
| `is_main`, `priority` | Рекомендация `reports/eda_emiss.md` (п. 7), а не фильтр. Основные (priority 1): пшеница озимая, пшеница яровая, ячмень яровой, подсолнечник, кукуруза на зерно; соя — 2; свёкла, картофель, рапс яровой, пшеница всего и овёс — 3 |
| `ggcmi_crop`, `ggcmi_proxy` | Культура календаря GGCMI. `proxy=True` означает, что у GGCMI такой культуры нет и взят аналог: овёс → ячмень, гречиха → просо, тритикале → озимая пшеница и т. п. |
| `max_plausible_t_ha` | Верхний предел правдоподобной урожайности, т/га (по группе культур; кукуруза — 16, свёкла — 90, лён на волокно — 4) |

## 3. `yield_panel.parquet` — главная таблица урожайности

Ключ: `okato × crop_code × farm_category_code × year`. Уровни (`region_level`): `subject` (89 каноничных кодов), `fo`, `rf`. Годы — 2000–2025. Строка есть, если есть урожайность (31533) или валовой сбор (30950) культуры, которая есть в 31533. Источники: ЕМИСС 31533 (ц/га на убранную площадь), 31328 (посевная площадь, тыс. га), 30950 (валовой сбор, тыс. ц).

| колонка | ед. | описание |
|---|---|---|
| `value_raw` | ц/га | Урожайность как в ЕМИСС. NaN — нет данных или значение скрыто (999999999) |
| `value_clean` | ц/га | Значение после правил чистки (ниже) |
| `yield_t_ha` | т/га | `value_clean / 10` — **основная цель** |
| `yield_filled_t_ha`, `fill_method` | т/га | `yield_t_ha` плюс заполнения: `derived_components` — «всего» из компонентов (озимая + яровая) с весами посевных площадей того же года, если `yield_t_ha` нет (в основном 2000–2006); `interpolated` — одиночный пропуск между двумя соседними годами (среднее соседей) |
| `is_interpolated`, `is_derived` | | То же в виде флагов |
| `area_kha`, `area_code`, `area_from_alias`, `area_confidential` | тыс. га | Посевная площадь (31328) по коду `area_code`; взята ли с кода-алиаса; скрыта ли |
| `gross_tc`, `gross_kt`, `gross_confidential` | тыс. ц, тыс. т | Валовой сбор (30950) |
| `yield_calc_t_ha` | т/га | Расчётная урожайность = сбор / **посевная** площадь. Есть и за 2025 г., хотя в 31533 этого года ещё нет. Для калькулятора «сколько соберу с поля» это правильнее, чем урожайность на убранную площадь: в ней не учтена гибель посевов |
| `harvest_share` | доля | h = сбор / (`value_raw` × посевная) ≈ доля убранной площади. В норме 0,8–1,0 |
| `series_median` | ц/га | Медиана положительных значений ряда «регион × культура × категория» |
| `run_len` | лет | Длина непрерывного отрезка с `value_clean`, в который попадает строка (0 — значения нет) |
| `series_n_years`, `series_max_run` | лет | Число лет с `value_clean` в ряду и самый длинный непрерывный отрезок |
| `okato_src` | | Исходный код ЕМИСС |

**Флаги и правила чистки** (флаг ставится всегда, `value_clean = NaN` — только где указано):

| флаг | правило | в `value_clean` |
|---|---|---|
| `flag_confidential` | В ЕМИСС стоит 999999999 (скрыто Росстатом, в основном 2018–2021) | NaN |
| `flag_zero` | Значение 0 | NaN (нули считаются пропусками) |
| `flag_negative` | Значение < 0 | NaN |
| `flag_outlier_hi` | Больше 3 × медиана ряда | NaN, **если** выброс не подтверждён сбором и площадью (`outlier_confirmed_by_calc`: h ∈ [0,5; 1,05]). Так сохраняется реальный рост культуры в регионе (подсолнечник и соя в Сибири) |
| `outlier_confirmed_by_calc` | Выброс `flag_outlier_hi` согласуется с расчётной урожайностью | значение остаётся |
| `flag_implausible` | т/га > `max_plausible_t_ha` культуры (явные ошибки ввода: Липецкая обл., ячмень озимый 2022 = 33 748 ц/га) | NaN |
| `flag_outlier_lo` | Меньше медианы ряда / 3 (провалы 2010 и 2024 гг., ранние годы с крошечной площадью) | остаётся |
| `flag_jump` | Скачок год к году больше чем в 3 раза | остаётся |
| `flag_calc_mismatch` | h < 0,5 или h > 1,05: урожайность не согласуется со сбором и посевной | остаётся |

Ограничения:
- Урожайность 31533 считается **на убранную площадь**, годовой убранной площади нет. В засуху урожайность занижает потери: смотрите `yield_calc_t_ha` и `harvest_share`.
- Полевые культуры есть за 2000–2024 гг. За 2025 г. в 31533 только плодово-ягодные; по полевым культурам есть сбор и площадь, то есть `yield_calc_t_ha`. Итоги 2025 г. выйдут после 06.04.2027.
- Ряды «в весе после доработки» по масличным обрываются в 2022–2023 гг. Подсолнечник 3080000 и соя 3100000 идут без доработки до 2024 г.
- У сои в ~7 % случаев h > 1,02 — вероятно, урожайность и сбор приведены к разному весу (до или после доработки).
- Овощи по видам есть только за 2000–2007 гг.

## 4. `yield_operational.parquet` — оперативные данные 2023–2026

Ключ: `measure × okato × crop_code × farm_category_code × year × period`. Источники: 33978 (намолочено с 1 га, ц/га, СХО), 34165 (собрано, тыс. т, все категории хозяйств), 33784 (убрано, тыс. га, СХО). Срезы — «на 1 июля» … «на 1 ноября»; за 2026 г. — до 1 октября (34165 — до 1 сентября).

| колонка | описание |
|---|---|
| `measure` | `yield_oper_c_ha`, `gross_oper_kt` или `harvested_area_kha` |
| `period`, `period_date`, `is_latest_period` | Срез, его дата и признак последнего среза года по показателю |
| `final_crop_code` | Код культуры итоговой урожайности: 1070102 «зерновые без кукурузы» → 1000001 (итог **с** кукурузой); свёкла 3060500 → 3060100; подсолнечник 3080100 → 3080000 |
| `value_t_ha` | Урожайность, т/га (только для `yield_oper_c_ha`) |
| `bias_vs_final_pct` | Известное смещение оперативных данных против итогов 31533 (СХО), медиана за 2023–2024 на 1 ноября: зерновые −3,2 %, свёкла −7 %, подсолнечник −1,5 %, картофель +0,2 % |
| `value_t_ha_bias_adj` | `value_t_ha / (1 + bias/100)` — грубая поправка. На ранние срезы она переносится условно |

## 5. `weather_region_season.parquet` — погода «регион × сезон»

Ключ: `okato × year` (year — год урожая). 89 регионов, сезоны 2001–2027. Сезон 2027 содержит только сентябрь–октябрь 2026 г. — это условия посева озимых. Источник: ERA5-Land (0,1°) и ERA5 (0,25°) почасово из бакета Open-Meteo. Сутки считаются по местному солнечному времени, затем месяц — по точке, затем регион — среднее по точкам пашни с весом доли пашни. Суточная агрегация и ET0 (FAO-56 Penman–Monteith) — из `src/data/build_weather_daily.py`.

Месячные колонки `<переменная>_<тег>` (тег `p09…p12`, `01…10`). Месяц с < 25 сутками данных — NaN: например, октябрь 2026 г. (данные по 22.10.2026).

| переменная | ед. | что это |
|---|---|---|
| `tmean`, `tmax`, `tmin` | °C | Средняя за месяц суточная средняя, максимальная и минимальная температура |
| `tmax_abs`, `tmin_abs` | °C | Абсолютный максимум и минимум месяца |
| `tdew` | °C | Точка росы |
| `prec`, `snowfall` | мм | Осадки и снегопад (водный эквивалент) за месяц |
| `rad` | Вт/м² | Средняя суммарная коротковолновая радиация |
| `wind` | км/ч | Средняя скорость ветра на 10 м (единицы Open-Meteo) |
| `vpd` | кПа | Средний дефицит упругости водяного пара (es − ea) |
| `sm0_7`, `sm7_28`, `sm28_100` | м³/м³ | Влажность почвы в слоях 0–7, 7–28 и 28–100 см (ERA5-Land), среднее за месяц |
| `snow_depth` | м | Высота снега (ERA5-Land; в 2022 г. в сырье пробел) |
| `tsoil_min` | °C | Минимальная температура почвы 0–7 см |
| `et0` | мм | Эталонная эвапотранспирация FAO-56 за месяц |
| `cwb` | мм | Климатический водный баланс P − ET0 |
| `gdd5`, `gdd10` | °C·сут | Суммы активных температур Σ(tmean − 5)⁺ и Σ(tmean − 10)⁺ |
| `hot30`, `hot35` | сут | Число дней с tmax > 30 и > 35 °C. Считается по точкам, затем усредняется: это ожидаемое число жарких дней на пашне региона |
| `frost0`, `frost2` | сут | Число дней с tmin < 0 и < −2 °C |
| `dry_days`, `dry_spell` | сут | Число дней с осадками < 1 мм и самая длинная серия таких дней в месяце |
| `prec_act`, `t_act` | мм, °C·сут | Осадки и сумма температур за сутки с tmean > 10 °C (для ГТК) |
| `htc` | — | **ГТК Селянинова** = 10·Σprec / Σt за сутки с t > 10 °C; NaN, если Σt < 100 °C. < 0,7 — засуха, 1,0–1,5 — достаточное увлажнение |

Сезонные агрегаты (NaN, если хотя бы один месяц неполон):

| колонка | что это |
|---|---|
| `gdd5_4_9`, `gdd10_4_9` | Суммы активных температур за апрель–сентябрь |
| `prec_4_8`, `et0_4_8`, `cwb_4_8`, `tmean_4_8` | Осадки, ET0, водный баланс и средняя температура за апрель–август |
| `prec_p09_03` | Осадки за сентябрь Y−1 – март Y: запас влаги к весне |
| `hot30_5_8`, `hot35_5_8` | Жаркие дни за май–август |
| `frost0_4_5`, `frost0_9_10` | Поздние весенние и ранние осенние заморозки |
| `htc_5_8` | ГТК за май–август |
| `dry_spell_4_8` | Самая длинная засушливая серия за апрель–август (по точкам, затем среднее) |
| `tsoil_min_win`, `cold20_win`, `snow_win`, `thaw_win` | Зима (декабрь–март): минимум температуры почвы, дни с tmin < −20 °C, средняя высота снега, дни оттепели (tmax > 3 °C в январе–феврале) |

Нормы и аномалии:
- `a_<колонка>` = значение − средняя региона за сезоны `clim_start_year`…`train_end_year` (2001–2021). Годы после `train_end_year` на норму не влияют, это проверяется тестом.
- `clim_tmean`, `clim_prec_4_8`, `clim_et0_4_8`, `clim_gdd5_4_9`, `clim_htc_5_8` — климат региона, те же годы.
- `norm_years`, `season_complete` (все 14 месяцев полные), `weather_last_date`.

**Ключевые признаки** (по корреляции с отклонением урожайности от тренда, `reports/model_weather.md`): для озимой пшеницы — `a_tmean_05`, `a_sm28_100_03`, `a_tmean_06`, `cold20_win`, `tsoil_min_win`; для яровых колосовых — `a_tmean_06`, `a_hot30_06`, `a_cwb_06`; для кукурузы, свёклы, сои и картофеля — `a_hot30_07`, `a_cwb_07`; засуха в целом — `htc_5_8`, `dry_spell_4_8`, `cwb_4_8`.

Ограничения: NASA POWER не используется (у `PRECTOTCORR` неверный масштаб). Облачности ERA5 за 2022 г. нет, но она и не нужна. Точки пашни — не обязательно поля конкретной культуры.

## 5a. `weather_region_month.parquet`

Те же месячные переменные в длинном виде: ключ `okato × year × month`, 2000-01 … 2026-10. `n_points` — число точек с данными. Удобно, чтобы задавать свои окна.

## 5b. `weather_crop_window.parquet` — погода в окне культуры

Ключ: `okato × crop_code × year`. Окно — месяцы от посева до созревания по `crop_calendar` (GGCMI, богара). У озимых окно начинается осенью Y−1, но не раньше сентября. `win_prec`, `win_et0`, `win_cwb`, `win_gdd5`, `win_gdd10`, `win_hot30`, `win_hot35`, `win_frost0` — суммы; `win_tmean`, `win_tmax`, `win_sm28_100`, `win_sm7_28` — средние; `win_htc` — ГТК окна; `win_months` — длина окна, мес. `a_win_*` — аномалии к норме региона и культуры за 2001…`train_end_year`. Окно задаётся с точностью до месяца.

## 6. `soil_region.parquet` — почвы

Ключ: `okato`. Источник: SoilGrids 2.0 (ISRIC, 250 м), статистика `mean` в точках пашни. Среднее по точкам с весом доли пашни; значения −32768 (вода, город) не учитываются.

| колонка | ед. | |
|---|---|---|
| `clay/sand/silt_<слой>` | % | Глина, песок, ил |
| `soc_<слой>` | г/кг | Органический углерод |
| `phh2o_<слой>` | pH | pH водной вытяжки |
| `nitrogen_<слой>` | г/кг | Общий азот |
| `cec_<слой>` | смоль(+)/кг | Ёмкость катионного обмена |
| `bdod_<слой>` | г/см³ | Плотность сложения |
| `cfvo_<слой>` | % объёма | Крупные фракции |
| `ocd_<слой>` | кг/м³ | Плотность органического углерода |
| `ocs_0_30` | т/га | Запас органического углерода 0–30 см |
| `wrb_dominant`, `wrb_dominant_share`, `wrb_second` | | Доминирующий класс WRB (наиболее вероятный в точке), его доля по весам точек и второй по доле класс |
| `elev_mean`, `elev_min`, `elev_max`, `elev_std` | м | Высота над уровнем моря в точках пашни: средняя с весом доли пашни, минимум, максимум и разброс. Источник — HSURF ячеек ERA5-Land (0,1°), для ячеек над морем — ERA5 (0,25°), `data/raw/era5_om/<model>/static_cells.csv`. −999 (море) — пропуск. Прикаспий ниже уровня моря (Астраханская обл. ≈ −10 м) |
| `era5_soil_type` | код | Доминирующий тип почвы ERA5 (1 — грубая … 6 — органическая; 0 — вода, считается пропуском) |

Слои: `0_30` — среднее по 0–5, 5–15 и 15–30 см с весами по мощности; `30_60` — слой 30–60 см. Слоёв влагоёмкости (wv0010/0033/1500) нет: их нет на файловом сервере ISRIC.

## 7. `ndvi_region.parquet` и `ndvi_region_year.parquet` — NDVI MODIS

Источник: MOD13Q1 v061, 16-дневные композиты 2000-02-18 … 2026-09-30, все 450 точек пашни (окно 3×3 пикселя, ~750 м). Значение = mean3x3/10000, если в окне ≥ 5 годных пикселей, иначе — центральный пиксель. Учитываются только композиты с `pixel_reliability` центра 0 (good) или 1 (marginal); 2 (снег), 3 (облака) и −1 отбрасываются.

`ndvi_region` — ключ `okato × date`:

| колонка | описание |
|---|---|
| `year`, `period` (1…23), `doy` | Год, номер 16-дневного композита в году, день года начала композита |
| `ndvi` | Среднее по годным точкам с весом доли пашни |
| `n_points`, `n_points_valid`, `n_points_good` | Число точек всего, годных (надёжность 0 или 1) и с надёжностью 0 |
| `valid_weight_share` | Доля веса годных точек, 0–1 |

`ndvi_region_year` — ключ `okato × year`, композиты с 7 апреля по 30 сентября:

| колонка | описание |
|---|---|
| `ndvi_max`, `ndvi_peak_doy`, `ndvi_peak_date` | Максимум за сезон и дата пика |
| `ndvi_mean_5_8` | Среднее за май–август |
| `ndvi_integral`, `ndvi_integral_interp_share` | Интеграл NDVI по дням (трапеции) после линейной интерполяции пропусков и доля заполненных композитов. Считается, если годных композитов ≥ 60 % |
| `ndvi_04…ndvi_09` | Среднее по месяцам |
| `n_periods`, `n_valid_periods`, `season_complete` | Полнота сезона (у 2026 г. композиты до 30.09) |

Ограничения: точка пашни — не обязательно поле нужной культуры, поэтому связь с урожайностью слабее погодной. LAI, FPAR, LST и GPP — в разделе 7a.

## 7a. `modis_extra_region.parquet` и `modis_extra_region_year.parquet` — LAI/FPAR, LST, GPP MODIS

Источники (Planetary Computer, каталог — `data/README_data.md`, раздел 7a): MOD15A2H (LAI, FPAR, 500 м), MOD11A2 (LST день и ночь, 1 км), MOD17A2H (GPP, 500 м). Это 8-дневные композиты, только апрель–октябрь, 177 точек пашни с `rank_in_region ≤ 1`. На регион приходится 2 точки, у Сахалинской обл. — одна; по сравнению с NDVI (до 15 точек) оценка заметно шумнее. Регион — среднее по точкам с весом доли пашни.

Качество и шкалы:

| переменная (`var`) | ед. | правило |
|---|---|---|
| `lai` | м²/м² | Центральный пиксель × 0,1. Годен, если ≤ 100 (249–255 — не растительность или заполнитель) и SCF_QC (биты 5–7 `FparLai_QC`) = 0 или 1 (основной алгоритм) |
| `fpar` | доля 0–1 | Центральный пиксель × 0,01, те же правила QC |
| `lst_day`, `lst_night` | °C | mean3x3, если в окне ≥ 5 годных пикселей, иначе центр; × 0,02 − 273,15; 0 — заполнитель; годны −60…+75 °C. День — только при битах 0–1 `QC_Day` = 0 или 1. Для ночи QC в выгрузке нет, проверяется только заполнитель |
| `lst_diff` | °C | `lst_day − lst_night` в той же точке и композите (суточная амплитуда; растёт при засухе и закрытии устьиц) |
| `gpp` | г C/м² за 8 суток | mean3x3 или центр × 0,1; годны 0…3000 raw (32761–32767 — заполнители, > 300 г C/м² за 8 суток на пашне невозможно). QC в выгрузке нет. **Скачано только 2021–2026 гг.** |

`modis_extra_region` — длинная таблица, ключ `okato × var × date`; колонки `product` (lai/lst/gpp), `year`, `period` (1…46, номер 8-дневного композита), `doy`, `value`, `n_points`, `n_points_valid`, `valid_weight_share`.

`modis_extra_region_year` — ключ `okato × year`, 2000–2026, по композитам апреля–октября. Для каждой переменной `<var>` ∈ {lai, fpar, lst_day, lst_night, lst_diff, gpp}:

| колонка | описание |
|---|---|
| `<var>_max`, `<var>_mean`, `<var>_peak_doy` | Максимум и среднее за сезон, день года максимума |
| `<var>_integral` | Интеграл по дням (трапеции, пропуски интерполированы) при ≥ 60 % годных композитов из ≥ 20. У GPP — сезонная сумма, г C/м² |
| `<var>_04 … <var>_10` | Средние по месяцам — **маскируются по дате прогноза так же, как NDVI** |
| `<var>_n_valid` | Число годных композитов за сезон |
| `<var>_a<признак>` | Аномалия к норме региона, например `lai_a07` или `lst_day_amean`. Норма — среднее по годам ≤ `train_end_year` (2000–2021), и только если в норме ≥ 5 лет. **У GPP аномалий нет**: до 2021 г. ряда нет |
| `modis_n_points` | Число точек MODIS в регионе (1 или 2) |

Сезонные агрегаты (`max`, `mean`, `integral`, `peak_doy`) известны только после окончания сезона (конец октября). Для прогноза по ходу сезона используйте месячные колонки до даты прогноза.

## 8. `crop_calendar.parquet` — календарь посева и уборки

Ключ: `okato × crop_code` — все культуры, у которых есть `ggcmi_crop`. Источник: GGCMI Phase 3 (Jägermeyr et al., 2021, сетка 0,5°), значения в точках пашни. Если в ячейке пусто, берётся ближайшая непустая ячейка в окне ±1°. Регион — циркулярное среднее дня года с весом доли пашни.

| колонка | описание |
|---|---|
| `plant_doy_rf`, `maturity_doy_rf`, `season_length_rf` | День года посева и созревания, длина сезона в днях, богара (основное) |
| `*_ir` | То же при орошении (справочно) |
| `plant_mmdd`, `maturity_mmdd`, `plant_month`, `maturity_month` | Те же даты в формате ММ-ДД и месяцы |
| `sown_previous_year` | Посев в прошлом году (озимые) |
| `ggcmi_crop`, `ggcmi_proxy`, `season_type` | Из `crops` |
| `n_points`, `n_points_valid`, `n_points_neighbor` | Число точек; годных; взятых из соседней ячейки |

Ограничение: GGCMI — глобальный продукт для климатической эпохи около 2000-х, без межгодовой изменчивости. Для озимой пшеницы на юге он даёт посев около 7 сентября; по агрономической практике Кубани посев идёт в конце сентября – октябре. Даты подходят для привязки окон с точностью до месяца.

## 9. `prices.parquet` и `prices_crop_map.parquet` — цены производителей

`prices` — ключ `okato × product_id × year`; 89 субъектов плюс строка РФ (`okato = 643`), 1999–2026 гг. Источники: ЕМИСС 31454 (ОКПД, 1999–2016) и 57693 (ОКПД2, 2017–2026). Единицы — руб./т, годовая цена — период «январь-декабрь».

| колонка | описание |
|---|---|
| `product_id`, `product_name` | Продукт (21 шт.: пшеница, ячмень, кукуруза, семена подсолнечника, бобы соевые, рапс, сахарная свёкла, картофель, …, классы пшеницы) |
| `price` | Номинальная цена после подстановки |
| `price_source` | Откуда цена: `region` — цена субъекта; `fo` — среднее по субъектам ФО в том же году; `rf` — цена РФ |
| `price_region`, `price_fo`, `n_fo_subjects`, `price_rf` | Все три уровня иерархии |
| `price_real`, `deflator`, `price_base_year` | Цена в рублях базового года. Дефлятор — среднегодовой индекс цен производителей **всей** с/х продукции РФ (ОКПД/ОКПД2 «01»), собранный из месячных индексов «к декабрю предыдущего года» 31110 и 57740. Свой индекс продукта для дефлирования не используется: он убрал бы саму динамику цены продукта |
| `is_partial_year`, `n_months` | Неполный год: 2026 — «январь-сентябрь» |
| `source_indicator`, `product_code_src`, `okato_src` | Исходный показатель, код ОКПД или ОКПД2, исходный код территории |

Стык: годы 31454 и 57693 не пересекаются, продукты сопоставлены по названию. Кукуруза внутри 57693 сменила код (01.11.2 → 01.11.20 с 2024 г.). Отношение цены РФ 2017/2016: 0,6–1,1. Это реальное падение цен в 2017 г. (рекордный урожай), а не разрыв рядов. Ограничение: по свёкле, сое, подсолнечнику и рапсу цены субъекта есть лишь в 25–45 регионах, остальное подставлено по ФО или РФ.

`prices_crop_map` — продукт цены ↔ `crop_code` урожайности: например, `wheat` → 1010400, 1010500, 1010401; `sunflower` → 3080000, 3080102.

Длинный формат. Ключ: `indicator_id × okato × item_code × farm_category_code × year`. Почти всё — по с/х организациям.

| `indicator_id` | показатель | ед. | охват |
|---|---|---|---|
| 30963 | Минеральные удобрения, внесено всего (100 % д. в.), по группам культур | тыс. ц | субъекты, 1990–2025 |
| 30964 | Минеральные удобрения на 1 га посева, по группам культур | кг д. в. | субъекты, 1990–2025 |
| 30965 / 30966 | Органические удобрения всего / на 1 га посева | тыс. т / т | субъекты |
| 31632 | Энергомощности на 100 га посевной площади | л. с. | субъекты, 1990–2025 |

Колонки: `item_code` и `item_name` — культура или вид техники; `coverage` — `subjects` или `rf_only`; `n_subjects` — число субъектов с данными по позиции в году; `confidential` — значение скрыто. ## 11. `model_table.parquet` — склейка для моделирования

Ключ: `okato × crop_code × year`; только субъекты, одна категория хозяйств (`--category`), все культуры (или `--crops`). Строка есть, если в регионе есть урожайность, площадь или сбор культуры. Модели не обучаются.

| группа колонок | описание |
|---|---|
| Цель и контекст | `yield_t_ha` (цель), `yield_filled_t_ha`, `fill_method`, `yield_calc_t_ha`, `harvest_share`, `area_kha` (площадь года t известна весной), `area_lag1`, `gross_kt`, флаги качества, `run_len`, `series_max_run`, `is_main`, `crop_group` |
| `y_hist` | Ряд для трендов: наблюдённые значения и значения «всего», досчитанные из компонентов того же года. **Без** интерполяции: интерполированное значение использует год t+1 |
| `tr_*` — тренд, только годы < t | `tr_lag1`, `tr_lag2`; `tr_mean3` (≥ 2 знач.), `tr_mean5` (≥ 3 знач.), `tr_median10`; `tr_lin_all` — линейный тренд по всем прошлым годам (≥ 5 точек), прогноз на t; `tr_lin10` — то же по t−10…t−1; `tr_n_past`, `tr_n_10`, `tr_last_year` |
| `target_dev_tr_lin10` | `yield_t_ha / tr_lin10 − 1` — цель «отклонение от тренда» (содержит y_t, это **не** признак) |
| Погода | Сезонные агрегаты, `clim_*` и все `a_*` из `weather_region_season`; `weather_season_complete` |
| Окно культуры | `win_*`, `a_win_*`, `win_months` (см. 5b) |
| Календарь | `cal_plant_doy_rf`, `cal_maturity_doy_rf`, `cal_season_length_rf`, `cal_sown_previous_year`, `cal_ggcmi_proxy` |
| Почвы и рельеф | `soil_*`, `elev_*` (см. 6) |
| NDVI | `ndvi_*` из `ndvi_region_year`. Это данные текущего сезона: для прогноза на дату их надо обрезать по дате |
| MODIS LAI/FPAR, LST, GPP | `lai_*`, `fpar_*`, `lst_day_*`, `lst_night_*`, `lst_diff_*`, `gpp_*`, `modis_n_points` из `modis_extra_region_year` (см. 7a). Месячные `<var>_<мм>` и `<var>_a<мм>` маскируются по дате прогноза, сезонные агрегаты известны после октября |
| Служебные | `train_end_year`, `is_train_year` |

Чего здесь нет и что надо делать в модели: обрезать погоду по дате прогноза (месяцы после даты прогноза в сезонных колонках уже фактические) и выбрать культуры, регионы и пороги (средний посев ≥ 5 тыс. га, ряд ≥ 15 лет — рекомендации EDA).
