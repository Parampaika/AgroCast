# Агрокаст: прогноз урожайности и оптимизация структуры посевов

Решение кейса «Своё Фермерство → Задача 5. Калькулятор прогноза урожайности» стипендиального конкурса Россельхозбанка 2026–2027. Автор: Даниил Соболев, аспирант СПбПУ (спец. 5.2.2, Data Science).

> Работа участника конкурса. Не является продуктом или сервисом Россельхозбанка.

**Сайт-прототип:** <https://parampaika.github.io/AgroCast/>

## Что сделано

- **Данные.** 17 открытых источников: ЕМИСС (урожайность, площади, сбор, цены), погода ERA5 по 450 точкам пашни, NASA POWER, почвы SoilGrids, спутник MODIS (NDVI, LAI, FPAR, температура поверхности), календари посева GGCMI, FAOSTAT, USDA PSD, Госреестр сортов. Четыре слоя: raw → interim → processed → clean. Чистый слой `model_table` — 683 признака на «субъект × культура × год».
- **Прогноз.** Модель «тренд × погода»: цель — отклонение урожайности от тренда. Пять дат прогноза в сезоне (1 мая, 1 июня, 1 июля, 1 августа, конец сезона), семь культур, 80-процентные конформные интервалы, объяснение вкладов факторов (SHAP).
- **Честная проверка.** Скользящая по времени проверка 2012–2025: тренды, нормы погоды и обучение используют только прошлые годы, погода и спутник после даты прогноза маскируются.
- **Лесенка моделей** (MAE, т/га, среднее по культурам, конец сезона): «прошлый год» 1,48 → тренд без погоды 1,30 → тренд + погода (Ridge) 0,99 → бустинг по умолчанию 1,01 → Optuna + ансамбль **0,95** (−30 % к ступени 0). Подробно — [reports/ladder.md](reports/ladder.md).
- **Перебор моделей.** Больше тысячи конфигураций (Ridge, ElasticNet, RF, ExtraTrees, HGB, LightGBM, CatBoost, XGBoost, ансамбли, Optuna) — [reports/sweep.md](reports/sweep.md).
- **Оптимизация посевов** (сверх кейса). Сценарная стохастическая оптимизация структуры посевов с риск-мерой CVaR и ограничением на отклонение от текущего плана: «изменить план немного — получить заметный эффект». Линейная программа, проверка на отложенных годах — [reports/optimization.md](reports/optimization.md).
- **Сайт.** Статический, без бэкенда: карта прогноза, карточка региона, калькулятор, оптимизация, методика. Код — [web/](web/).

## Ограничения

- Итогов Росстата по полевым культурам за 2025 год ещё нет: урожайность 2025 восстановлена как «сбор / посевная площадь».
- Оценка 2026 года на дату «конец сезона» построена по фактической погоде завершившегося сезона и не сверена с итогами Росстата.
- Вклад спутниковых признаков в точность скромный (в пределах 1–2 п. п. к модели без них); основную точность даёт погода.
- Ранние прогнозы (1 мая) заметно слабее поздних.
- Затраты на гектар в оптимизации — допущения (открытых нормативов нет), цены — ЕМИСС.
- Выбор набора признаков и тренда видел все годы проверки, поэтому метрики немного оптимистичны; гиперпараметры подбирались по 2012–2018.

## Структура репозитория

| папка | что |
|---|---|
| `docs/` | кейс, формат сдачи, идея, обзор методик, контракт данных сайта |
| `scripts/download/`, `scripts/parse/` | загрузка и разбор сырых данных |
| `src/preprocess/` | сборка чистого слоя `data/clean/` |
| `src/model/` | перебор моделей, лесенка, итоговые модели и выгрузка |
| `src/optimize/` | оптимизация структуры посевов |
| `src/report/`, `src/deck/` | генераторы научного отчёта и презентации |
| `web/` | сайт (HTML + CSS + JS, ECharts) |
| `reports/` | отчёты с графиками и таблицами |
| `report/out/`, `deck/out/` | научный отчёт (docx, pdf) и презентация (pptx, pdf) |
| `tests/` | тесты (60) |

Исходные и промежуточные данные (`data/raw`, `interim`, `processed`, `clean`, `model`) в репозиторий не входят из-за объёма. Их воспроизводят скрипты загрузки и сборки; каталог источников — [data/README_data.md](data/README_data.md).

## Запуск

Нужны [uv](https://docs.astral.sh/uv/) и Python 3.12.

```bash
uv sync
```
```bash
uv run pytest -q
```
```bash
uv run python -m http.server -d web 8000
```

Сайт откроется на <http://localhost:8000>. Пересборка чистого слоя — `uv run python -I -X utf8 src/preprocess/build_all.py`.
