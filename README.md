# РСХБ: калькулятор прогноза урожайности

Решение кейса «Своё Фермерство → Задача 5» стипендиального конкурса Россельхозбанка 2026–2027. **Срок: 30.10.2026.**

Прогноз урожайности (т/га и общий объём) по субъекту РФ и культуре на открытых данных — урожайность ЕМИСС, погода ERA5, почвы SoilGrids, NDVI MODIS — плюс оптимизация структуры посевов: что изменить в плане немного, чтобы получить заметный эффект.

## Где что

| папка | что |
|---|---|
| `docs/` | кейс, формат сдачи, идея, обзор методик, ТЗ |
| `scripts/download/`, `scripts/parse/` | загрузка и сырой разбор данных |
| `src/data/` | исследовательские скрипты (на них опираются отчёты) |
| `src/preprocess/` | сборка чистого слоя `data/clean/` |
| `reports/` | отчёты, графики, таблицы |
| `tests/` | проверки чистого слоя |

Данные (`data/raw`, `interim`, `processed`, `clean`) в git не входят. Их воспроизводят скрипты загрузки и сборки.
