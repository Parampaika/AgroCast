# Наша идея

Выбран кейс **Задача 5 «Калькулятор прогноза урожайности»** (профиль ИТ, «Своё Фермерство»). Карту эпизоотий (Задача 6) не берём.

Суть: не просто «модель предсказала N т/га», а прогноз, который превращается в рекомендацию — **что изменить в плане немного, чтобы получить заметный эффект**.

## Часть 1. Прогноз

- Цель: урожайность (ц/га → т/га) по региону, культуре и году; общий объём = урожайность × площадь.
- Модель: градиентный бустинг (CatBoost/XGBoost) на панели «регион × год» с признаками погоды и почвы. Объяснение факторов — SHAP.
- Предсказываем **отклонение от тренда**, а не абсолют: урожайность растёт из-за технологий, иначе модель выучит год.
- Валидация только по времени (обучение до 2021, тест 2022–2024), не случайный сплит.
- Выход — не точка, а **распределение по погодным сценариям** (прогоняем модель на погоде прошлых ~15 лет).

## Часть 2. Оптимизация (главная фишка)

Фермер вводит регион, площадь и текущий план посевов, например 60% пшеница / 25% подсолнечник / 15% ячмень.

1. Для каждой культуры получаем распределение урожайности по сценариям.
2. Умножаем на цены производителей и вычитаем затраты → распределение прибыли для любого плана.
3. Ищем план с максимальной ожидаемой прибылью и ограниченным убытком в плохой год (стохастическая оптимизация, scipy или PuLP).
4. Ограничения: менять не больше X% площадей от текущего плана (X = 10–15%); севооборот (например, подсолнечник не больше 20–25%).
5. Результат: «переведите 10% площади с пшеницы на ячмень: ожидаемая прибыль +A%, убыток в неурожайный год −B%» и кривая «насколько сильно меняем план → сколько выигрываем» (первые 5–10% изменений дают основную часть эффекта).

Это прямой ответ на требование кейса «объясните пользу для планирования затрат и доходов».

## Часть 3 (дополнение, если останется время). Удобрения

Модуль «до какой дозы удобрения окупаются при текущих ценах». **Осторожно:** на региональных данных модель выучит корреляцию, а не причину (богатые южные регионы и удобряют больше, и урожай выше из-за климата). Отдачу от удобрений брать из агрономических справочников (кривые «доза → прибавка»), модель использовать только для погодной части.
