# Агрокаст — веб-прототип калькулятора урожайности

Статический сайт без сборки: HTML + CSS + ванильный JS (ES-модули) и [Apache ECharts 5.5.1](https://echarts.apache.org/) (лежит в `vendor/`, лицензия Apache-2.0 — `vendor/echarts.LICENSE.txt`). Работает без интернета, подходит для GitHub Pages из папки `web/`. Решение участника конкурса, кейс «Своё Фермерство», задача 5; не продукт банка.

## Запуск

```bash
uv run python -m http.server -d web 8000
```

Открыть <http://localhost:8000>. Файл `index.html` напрямую (через `file://`) не откроется: браузер не даст загрузить JSON и модули.

Для разработки удобнее сервер без кэша — правки JS видны сразу:

```bash
uv run python -I src/web_export/serve.py 8000
```

Пересобрать данные (≈1 мин, ~1 МБ JSON):

```bash
uv run python -I -X utf8 src/web_export/make_mock.py
```

## Экраны

| экран | адрес | что показывает |
|---|---|---|
| Обзор | `#/overview` | Карта России (прогноз т/га или отклонение от тренда), выбор культуры, шкала дат 1 мая → конец сезона с проигрыванием, KPI по РФ, уточнение прогноза, крупнейшие регионы |
| Регион | `#/region/<okato>` | История 2000–2025 + тренд + веер прогноза, факторы погоды, погода сезона против нормы (температура, осадки, ГТК), почвы, все культуры региона |
| Калькулятор | `#/calc` | Регион, площадь, структура посевов, поправки на почву, сорт и агротехнику → т/га и объём по культурам, выручка, затраты, маржа, плохой / обычный / хороший год |
| Оптимизация | `#/optimize` | Текущий план → рекомендованный при ограничении «менять не больше X %» и уровне осторожности: дифф планов, эффект, кривая «X → выигрыш», прибыль по погодным сценариям |
| Методика | `#/method` | Источники данных, схема расчёта, точность против бейзлайнов, выигрыш по дате прогноза, ограничения |

Светлая и тёмная тема (по системе или кнопкой), адаптивная вёрстка до 360 px.

## Данные: что реальное, что заглушка

Реальные (из `data/clean`): границы, история урожайности и площадей, тренды, погода сезона и нормы, почвы, цены производителей. Заглушки (`"mock": true`, в интерфейсе — плашка «демо-данные»): прогноз по датам, вклады факторов погоды, сценарии урожайности, затраты на гектар и поправки, метрики (результаты предварительной модели).

## Как подставить реальные результаты модели

Записать файлы `forecast.json`, `drivers.json`, `scenarios.json`, `metrics.json` в формате [docs/06_ui_data_contract.md](../docs/06_ui_data_contract.md) с `"mock": false`. Код сайта менять не нужно.

## Оптимизация

Матрица «культура × сценарий → прибыль на 1 га» = урожайность сценария × поправки × цена − затраты. Цель — `(1 − λ) · средняя прибыль + λ · средняя прибыль худших 20 % сезонов`, где λ — «осторожность». Ограничения: сумма долей = 1, доля культуры ≤ `max_share`, перенесённая площадь ≤ X, новые культуры — только отмеченные. Убывающая отдача: изменение доли культуры на Δ снижает выручку на `β·Δ²/2` (предшественники, худшие участки, перестройка севооборота). Решатель — жадные переносы площади шагом 0,5 %, задача вогнутая, поэтому результат близок к оптимуму.
